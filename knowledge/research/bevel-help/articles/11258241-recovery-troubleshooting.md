# Recovery Troubleshooting

**Category:** Recovery  
**Source:** https://help.bevel.health/en/articles/11258241

Why isn’t my Recovery Score showing? If your Recovery Score is not appearing in the Bevel app, follow the steps below to identify and resolve the issue. Note: Recovery data will only begin to appear after you've completed two full nights of sleep. 1. Make sure you wear your watch to sleep. The Recovery Score requires sleep data to be generated. Please confirm that: You wore your Apple Watch while sleeping Your sleep data includes sleep stages Sleep data is visible: In Apple Health In the Bevel app If sleep data is missing or incomplete, the Recovery Score cannot be calculated. 2. Check that HRV and RHR data are available in Apple Health. The Recovery Score also relies on: Heart Rate Variability (HRV) Resting Heart Rate (RHR) Please open Apple Health and confirm that: HRV data is present Resting Heart Rate data is present The data is recent If HRV or RHR data is missing, or not captured during your Sleep window, the Recovery Score will not show. 3. Verify your Data Sources in Bevel. If the required data exists, the issue may be related to your selected data sources. In the Bevel app: Tap the profile picture in the top-left (this is Options) Select Data Sources Review the data sources for: Sleep HRV RHR Make sure that: Only your current and correct data sources are unhidden Any unnecessary or outdated data sources are hidden This ensures Bevel uses the correct data when calculating Recovery. 4. Check Calculation Settings If all of the above is set correctly and the Recovery Score is still missing: Tap the profile picture in the top-left (Options) Go to Customization Select Calculations Take a screenshot of this screen Please share this screenshot with our support team so we can investigate further. Why is my HRV data missing? If your HRV data is missing, here are a few things that might help: Please make sure you are wearing your Apple Watch to sleep. Please check that Apple Health has HRV data by going to Apple Health → Heart Rate Variability → Show All Data. If you’re using a 3rd-party device that’s not an Apple Watch, make sure to check the Data Sources are set up correctly in Profile → Data Sources. There might not be enough HRV samples during your Sleep. You can try turning on Afib History in the Apple Watch settings. By default, Bevel only calculates HRV during sleep. If you want it to use data from Mindfulness sessions, go to Profile → Customization → Calculations → Toggle on Mindfulness Session. Why is my RHR data missing? If your RHR data is missing, here are a few things that might help: Please make sure you are wearing your Apple Watch to Sleep. If it’s still missing, please check that your data is in Apple Health → Heart Rate → Show All Data. If you’re using a 3rd-party device that’s not an Apple Watch, make sure to check the Data Sources are set up correctly in Profile → Data Sources.
