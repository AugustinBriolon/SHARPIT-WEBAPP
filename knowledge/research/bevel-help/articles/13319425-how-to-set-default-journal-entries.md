# How to Set Default Journal Entries

**Category:** Journal  
**Source:** https://help.bevel.health/en/articles/13319425

For habits you don’t log frequently, you can set default values: These defaults will automatically apply to each new day. Default entries automatically populate each new Journal day. Steps to Set Default Journal Entries Open Bevel. Tap the Journal tab. Tap the three dots (...) in the top-right corner. Tap Set Default Entries. Choose the default state for each habit. Tap Save. You can also tap Reset All to Default at the bottom.
