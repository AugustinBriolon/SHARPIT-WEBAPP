# How to Connect an External Heart Rate Sensor

**Category:** Strength Builder  
**Source:** https://help.bevel.health/en/articles/13491457

You can connect a compatible Bluetooth heart rate sensor directly to an iPhone-only strength workout to view and record live heart rate data.  Note: External heart rate sensors are only supported for Strength Workouts using iPhone mode. They are not available for cardio workouts or iPhone + Apple Watch workouts. Before you start Make sure the following are enabled: Bluetooth is turned on. Bevel has permission to write Heart Rate data to Apple Health. Go to Settings → Privacy & Security → Health → Bevel → Heart Rate and enable the permission. If this permission is disabled, Bevel will not connect to the sensor. Make sure the device is listed as a data source in Bevel → Profile → Data Sources → Heart Rate and that it isn't hidden. Change or disconnect a sensor You can switch sensors before or during a workout. Before starting the workout: Open Live Data Source. Tap another sensor to switch devices. Tap the connected sensor or Apple Health to disconnect. You'll be asked to confirm before the sensor is removed. During a workout: Tap the three dots (...) in the top-right corner. Tap Live Data Source. Select another sensor or switch back to Apple Health. Switching sensors does not remove previously recorded heart rate data. Bevel combines readings from all connected sources into a single workout. Supported sensors Bevel supports standard Bluetooth heart rate sensors, including sensors that do not sync with Apple Health. Examples include: Fitbit Air Polar H10 Other compatible Bluetooth heart rate monitors
