# Absence and Pain Playbooks

> Decision trees for missed weeks, planned absence, and active pain/injury. Used by coach chat, plan generation, and session analysis — not medical advice.

---

## Principles

1. **Protect the athlete first** — when in doubt, reduce load or pause the goal.
2. **Name the choice** — continue / postpone / restart / cancel / lighten. Vague encouragement is not a playbook.
3. **Progressive return** — after gaps, rebuild volume before intensity; after pain, reassess zones before hard sessions.
4. Persist the chosen path as a durable memory note or training constraint so later weeks stay coherent.

---

## Missed training (absence)

| Situation                                       | Preferred action                           | Athlete message angle                                     |
| ----------------------------------------------- | ------------------------------------------ | --------------------------------------------------------- |
| 1–3 days missed, no pain                        | Continue with lighten of next hard session | Each session still counts; adapt next intensity           |
| Several weeks missed, goal still realistic      | Postpone race date or reduce weekly volume | Reporting the goal is wiser than grinding catch-up        |
| Several weeks missed, catch-up would spike load | Restart goal with progressive plan         | New progressive sessions feel better than compressed load |
| Continue is high injury risk                    | Cancel or plan a new lighter goal          | Continuing is very risky — recommend cancel or new goal   |
| Background / no-race goal stalled               | Restart with progressive sessions          | Relancer is more pleasant than forcing the old block      |

### Ramp rules after absence

- First return week: ≤60–70% of prior weekly load; no VO2 / race-pace blocks.
- Second week: add volume before intensity.
- Reintroduce threshold only when twin recovery is green and no new pain.

---

## Pain and injury

| Signal                                     | Action                                                                              |
| ------------------------------------------ | ----------------------------------------------------------------------------------- |
| Mild residual ache, known zone, improving  | Continue with zone strategy / protect the area; ask reassessment after next session |
| Pain increases during or after the session | Stop hard work; lighten or pause; open physical note                                |
| New sharp pain or red-flag pattern         | Pause goal intensity; urge professional care; do not invent diagnoses               |
| Return from injury                         | Treat as `RETURN` quality week; short progressive exposures; confidence gate        |

Use session-analysis `physicalReassessments` when an active note’s zone was loaded. Prefer `setTrainingConstraint` / injury memory over silent plan mutation.

---

## Coach outputs (typed proposals)

When absence or pain is detected, propose **one** primary action among:

- `CONTINUE` — keep goal, maybe lighten
- `LIGHTEN` — same dates, cut volume/intensity
- `POSTPONE` — shift goal date
- `RESTART` — rebuild progressive plan
- `PAUSE` — stop hard training until clearance

Always explain why in one short sentence tied to load or pain evidence.
